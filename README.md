# SilverSentinel · 盛世白银预警哨兵

> 面向 Windows 的白银行情监控、K 线、组合预警与信息辅助分析桌面工具。

| 项目 | 信息 |
| --- | --- |
| 当前版本 | **v1.2.0** |
| 项目类型 | Windows 桌面应用 |
| 技术栈 | Electron + Node.js |
| 当前状态 | 稳定迭代 |

---

## 项目概览

SilverSentinel 以 **融通金白银实时行情** 为核心数据源，提供实时价格、K 线、本地行情记录、组合预警、邮件/系统通知、AI 行情分析和悬浮窗等能力。

项目定位不是交易终端，而是长期运行的 **行情观察 + 条件预警 + 信息辅助分析** 工具。

---

## 核心能力

### 实时行情
- 监控白银销售价与回购价
- 显示今日最高、最低、昨收及涨跌金额/比例
- 明确展示连接中断、数据过期、时间倒退、买卖价不同步等异常状态
- 本地保存软件实际采集到的行情数据

### 实时 K 线
由本机收到的销售价聚合生成，支持：
- 5 秒
- 15 秒
- 30 秒
- 1 分钟
- 5 分钟
- 15 分钟
- 30 分钟
- 1 小时

支持缩放、拖动查看历史、返回最新、悬停查看 OHLC 与采样数。

> K 线只基于软件真实采集的数据，不伪造电脑关机、休眠或断网期间的历史行情。

### 多条件预警
支持价格阈值、穿越、涨跌金额/百分比、相对昨收、连续高低于、价格区间、买卖价差、日内回撤/反弹和时间窗口波动等组合条件。

每条规则可独立配置触发逻辑、重复提醒间隔、每日提醒上限和数据中断容忍时间。

### 通知中心
- Windows 系统通知
- 提示音
- 文字转语音
- SMTP 邮件
- 多收件人独立发送
- 失败邮件重试
- 通知记录筛选与查看

### AI 行情分析
配置 DeepSeek API Key 后，可结合当前报价和近期信息生成 1 天、3 天、1 周、1 个月多个时间维度的上涨 / 横盘 / 下跌概率、理由和风险摘要。

### 迷你悬浮窗
- 销售价 / 回购价
- 涨跌与今日高低
- 始终置顶
- 透明度
- 尺寸与位置记忆
- 多档信息密度

## 快速开始

### 开发运行

```bash
npm install
npm start
```

### 自动检查

```bash
npm run check
npm run verify:official
npm run smoke
```

普通用户优先从 GitHub Releases 下载正式 Windows 安装版或便携版。

生成 Windows x64 便携版：

## 数据、安全与使用边界

软件会在本机保存必要的运行数据，例如：
- 当日行情记录
- 预警规则与触发记录
- 通知与邮件重试队列
- 邮箱与收件人设置
- AI 配置与最近一次分析结果
- 主窗口、迷你窗与系统设置

邮箱授权码等敏感配置仅保存在本机，不提交到仓库。

电脑休眠、关机或断网时无法继续采集实时行情，也无法对缺失时段进行真实预警。

---

## 风险说明

- 行情来源依赖第三方公开数据协议，接口变化可能影响可用性
- 不同来源的历史价格不可在未校准口径时直接混用
- AI 结论仅用于辅助信息整理
- 本项目不构成任何投资、交易或收益承诺
