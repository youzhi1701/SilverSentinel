# SilverSentinel · 盛世白银预警哨兵

> 当前桌面应用版本：**1.2.0**

SilverSentinel 是一套面向 Windows 的白银行情监控与预警桌面工具。项目以 **融通金白银实时行情** 为核心数据源，提供实时价格、K 线、本地行情记录、组合预警、邮件/系统通知、AI 行情分析和悬浮窗等能力。

项目定位不是交易终端，而是一个长期运行的 **行情观察 + 条件预警 + 信息辅助分析** 工具。

---

## 核心功能

### 实时行情
- 监控融通金白银销售价与回购价
- 显示今日最高、最低、昨收及涨跌金额/比例
- 对连接中断、数据过期、时间倒退、买卖价不同步等异常状态做明确提示
- 本地保存当天采集到的真实行情数据

### 实时 K 线
由本机收到的实时销售价聚合生成 K 线，支持：
- 5 秒
- 15 秒
- 30 秒
- 1 分钟
- 5 分钟
- 15 分钟
- 30 分钟
- 1 小时

支持缩放、拖动查看历史、返回最新、悬停查看 OHLC 与采样数。

> K 线只基于软件实际采集到的数据，不会伪造电脑关机、休眠或断网期间的历史行情。

### 多条件预警
可创建多条预警规则，并组合多个条件，包括：
- 达到 / 高于 / 低于指定价格
- 向上 / 向下穿越价格
- 指定时间内上涨或下跌金额
- 指定时间内上涨或下跌百分比
- 相对昨收变化
- 连续高于 / 低于某价
- 进入 / 离开价格区间
- 销售价与回购价价差
- 从日内高点回落、从日内低点反弹
- 指定时间窗口内的波动幅度

每条规则可配置触发逻辑、重复提醒间隔、每日提醒上限和数据中断容忍时间。

### 通知中心
支持：
- Windows 系统通知
- 提示音
- 文字转语音
- SMTP 邮件通知
- 多收件人独立发送
- 失败邮件重试
- 通知记录筛选与查看

邮箱授权码等敏感配置保存在本机，不提交到仓库。

### AI 行情分析
支持配置 DeepSeek API Key 后手动运行 AI 行情分析，结合当前报价和近期信息生成：
- 1 天
- 3 天
- 1 周
- 1 个月

不同时间维度的上涨 / 横盘 / 下跌概率、理由、风险和消息摘要。

AI 分析仅用于信息整理与辅助判断，不构成投资建议。

### 迷你悬浮窗
提供独立迷你行情窗口：
- 销售价 / 回购价
- 涨跌
- 今日高低
- 始终置顶
- 透明度调节
- 尺寸与位置记忆
- 多档信息密度

## 本地运行

### 环境要求

建议使用当前稳定版 Node.js，并在 Windows x64 环境运行。

### 安装依赖

```bash
npm install
```

### 启动开发版

```bash
npm start
```

### 运行测试

```bash
npm test
```

完整检查：

```bash
npm run check
```

### 官方数据源验证

```bash
npm run verify:official
```

### 冒烟测试

```bash
npm run smoke
```

---

## Windows 构建

生成 Windows x64 便携版：

```bash
npm run pack
```

生成未封装目录：

```bash
npm run pack:dir
```

当前 Electron Builder 同时配置了 Portable 与 NSIS 安装形式。

## 数据与隐私

软件会在本机保存必要的运行数据，例如：
- 当日行情记录
- 预警规则与触发记录
- 通知与邮件重试队列
- 邮箱与收件人设置
- AI 配置与最近一次分析结果
- 主窗口、迷你窗与系统设置

电脑休眠、关机或断网时无法继续采集实时行情，也无法对缺失时段进行真实预警。

---

## 使用边界

- 行情来源依赖第三方公开数据协议，第三方接口变化可能影响可用性
- 东方财富等外部历史页面仅作为独立参考，不与融通金零售报价混为同一口径
- AI 结论属于辅助信息，不代表确定走势
- 本项目不构成任何投资、交易或收益承诺
